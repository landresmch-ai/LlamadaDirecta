# Cómo compilar sin Android Studio (con GitHub)

1. Crea una cuenta en github.com
2. Crea un nuevo repositorio vacío llamado LlamadaDirecta
3. Sube TODO el contenido de este ZIP a ese repo (botón Add file > Upload files)
4. Ve a la pestaña Actions > verás que empieza a compilar solo (Build APK)
5. Espera 2-3 minutos, entra al build, abajo en Artifacts descarga LlamadaDirecta-APK
6. Ese .apk lo instalas en los 2 celulares

No necesitas instalar nada en tu PC.
